1. **Application (2) and the integration half of Testing (1)**: there is no
   backend, database or end-to-end path, and the 35 passing tests are
   unit/component tests only. This is roadmap Tier A and it unlocks the
   criteria that need a running system.
2. **Containerization (2), Deployment (2) and the CD half of CI/CD (2)**:
   there is no Dockerfile/Compose file, no deployment, and no deploy job.
   Docker is unavailable in this container (`AGENTS.md` Project gotchas), so
   this needs the Docker-capable environment in roadmap step 16.
3. **Observability (2), Alerting (1) and On-Call Agent (2)**: there is no
   telemetry, alert rule or responder agent; all three need the instrumented,
   running application first.
